# Pi Browser Taskbar Phoenix

Development-only Phoenix adapter package skeleton. It contains a prebuilt browser bootstrap, so a
consuming application does not need Node or a JavaScript package manager.

Runtime task handling and the reversible installer arrive in the Phoenix tracer bullets. Until
then, this package exposes its version and packaged browser asset path as the stable foundation
seam.

## Build and verify

Run `bin/verify` from the repository root. The root check builds the Hex package, verifies lockstep
version metadata, and inspects the artifact for its generated browser bootstrap.

See the repository [architecture](../../docs/architecture.md) and
[canonical contract](../../contract/docs/index.md).
