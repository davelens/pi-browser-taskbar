# Pi Browser Taskbar Rails

Development-only Rails adapter package skeleton. It contains a prebuilt browser bootstrap, so a
consuming application does not need Node or a JavaScript package manager.

Runtime task handling and the reversible installer arrive in the Rails tracer bullets. Until then,
this package exposes its version and packaged browser asset path as the stable foundation seam.

## Build and verify

Run `bin/verify` from the repository root. The root check builds the gem, verifies lockstep version
metadata, and inspects the artifact for its generated browser bootstrap.

See the repository [architecture](../../docs/architecture.md) and
[canonical contract](../../contract/docs/index.md).
