# Rails example

This directory is owned by the examples module and is reserved for the later executable Rails
example. Built-gem conformance already installs the artifact into a clean conventional ERB host using
only the public generator, boots it, serves package assets without an asset pipeline or Node, submits
a CSRF-protected task, updates recognized generated content, runs the native inverse twice, and boots
outside development with the gem absent.

The equivalent public setup is:

```sh
bin/rails generate pi_browser_taskbar:install
bin/rails destroy pi_browser_taskbar:install
```

Nonstandard ERB hosts may pass `--layout app/views/layouts/internal.html.erb --mount /internal/pi`.
The future executable example will use these same package seams without example-only runtime code.
